# Teacher & Presentation Gallery Folder

Place any custom project photos, dataset reference images, screenshots, or teacher evaluation images in this folder (`public/teacher_gallery/`).

### Benefits:
- **Safe & Non-Disruptive**: Adding or removing images here does NOT alter or break the web application runtime or build output.
- **Direct Accessibility**: Any image added here (e.g. `sample_gesture.jpg`) can be viewed directly in your web browser at:
  `http://localhost:3000/teacher_gallery/sample_gesture.jpg`
- **Presentation Ready**: Perfect for keeping your documentation screenshots and physical gesture photos organized for project reviews.
